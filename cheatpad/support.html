Good to know
A code didn't work. What now?+

Cheats work in Story Mode only, never in GTA Online. Enter the buttons quickly, without pausing, and with the pause menu closed. In GTA 5 you can dial the code on the in-game phone instead, which works on every platform. If it still fails, tap Didn't work? on the code and then Report this code.

When do GTA 6 codes arrive?+

As soon as they're found and checked, starting on launch night, 19 November 2026. Cheatpad updates its code list by itself, without an app update. We never add codes before they're confirmed.

How do you check a code?+

Every code has to match in at least two independent sources before it's added, and each code lists its sources. When sources disagree, the code waits until a third source settles it.

Will a cheat affect my trophies or achievements?+

In GTA 5, using a cheat turns off trophies and achievements for the rest of that session. Load your save again to turn them back on. Each game's note in Cheatpad says how cheats behave there.

Is Cheatpad made by Rockstar Games?+

No. Cheatpad is an independent, unofficial guide made by Ludyem AS. It isn't affiliated with, endorsed or sponsored by Rockstar Games or Take-Two Interactive. It isn't the game.

Do I need an account?+

No. There's no account, no advertising and no tracking. The privacy policy has the detail.
